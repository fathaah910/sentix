# Changelog

All notable changes to Sentix will be documented in this file.

## [1.0.0] - 2026-09-05

### Added

- Positive, negative, neutral and mixed sentiment classification
- Rule-based sentiment scoring
- Negation handling
- Intensity modifiers
- Diminisher handling
- Contrast analysis
- Aspect-based sentiment detection
- Emotion detection
- Confidence scoring
- Explainable sentiment evidence
- Morphological normalization
- Punctuation-based sentiment modification

### Testing

- 173 automated tests
- Complete test suite passing

### Benchmark

- 97% accuracy on the current Sentix benchmark dataset
- 0.9632 Macro F1 score
- Comparison benchmark against VADER and TextBlob
